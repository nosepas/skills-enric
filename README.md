# Skill «presentacions-proa»

Skill de Claude per crear presentacions de l'Escola PROA (Solsona) amb la seva identitat corporativa: colors, tipografia Poppins, logotip, separadors de subtema, notes del presentador i llenguatge inclusiu.

## Què fa
- Pregunta primer si la presentació és per a **PowerPoint** o **Google Slides**.
- PowerPoint: fórmules com a equacions natives (OMML).
- Google Slides: fórmules com a text normal amb Unicode (sense LaTeX).
- Fons rosa amb 60 % de transparència, panells de color amb 50 % i sense vora, sense número de diapositiva.
- Títols amb majúscula inicial i d'un sol color.
- El logotip va incrustat dins la skill: no cal cap altre fitxer.

## Instal·lació
1. Descarrega aquest repositori com a ZIP (Code > Download ZIP).
2. A Claude, ves a la configuració de skills (Configuració > Personalització) i puja la carpeta `presentacions-proa` (o el ZIP, segons el que accepti la teva versió).
3. Demana a Claude, per exemple: «Fes una presentació sobre la pressió per a 3r d'ESO».

Al pla d'equip o d'empresa, l'administrador la pot afegir per a tot el professorat.
